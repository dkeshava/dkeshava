⚡ Concurrent In-Memory Cache & Key-Value Store

High-throughput, thread-safe in-memory cache implemented in Go.

Core Primitives: Built from scratch in Go (Golang) featuring O(1) LRU eviction (doubly linked list + hash map) and TTL-based background key expiration.
High-Throughput Concurrency: Utilized sync.RWMutex to allow concurrent, non-blocking read operations with exclusive write safety, eliminating lock contention.
Verification: Validated race condition resilience using Go's race detector (go test -race) under heavy concurrent read/write loads.
API Layer: Exposed RESTful HTTP endpoints (GET, SET, DELETE, /stats) with custom metrics reporting.
